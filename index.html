Shared context

A project memory that keeps growing.

What one agent learns, every agent can use. It stays on your Mac, whichever model you use next.

Learns which agent works best

Terminus notices how each agent's work turns out on your projects: kept or rewound, tests passing, whether you had to correct it. Then it suggests the agent with the best record for the task in front of you. Only an app that runs them all can see this.

Hands off at the limit

Hit your 5-hour limit mid-task? Another agent picks up where it stopped. Ask first, or switch automatically.

Memory it learns

Your plans

Your subscriptions, used the way each company allows.

Terminus never sees or stores your sign-in. Each agent signs in through its maker's own app, and Terminus follows each company's rules for apps like it.

Claude

Runs your own Claude Code.

Terminus starts the Claude Code you installed, unmodified, and you sign in with Anthropic's own sign-in (claude auth login). Your Pro or Max plan works everywhere in Terminus, teams and discussions included. Or use an Anthropic API key.

Anthropic's terms let products run the unmodified Claude Code with each person's own subscription. Several Claude agents at once use your plan's limits faster.

Codex (ChatGPT)

Runs OpenAI's open-source Codex.

You sign in with your ChatGPT plan through Codex's own login, and it works everywhere in Terminus. Usage counts against your plan's Codex allowance. Or use an OpenAI API key.

OpenAI supports using ChatGPT plans in third-party tools.

Antigravity (Google)

You stay in the driver's seat.

On a personal Google sign-in, Google allows Antigravity only while you drive it. So it answers your own messages directly, and in teams and discussions every message to it waits for you to read, edit and send. It's never used for background summaries or for other agents' questions.

With a Gemini API key it works everywhere. Google AI Pro and Ultra include monthly Gemini API credits you can claim in AI Studio. Gemini CLI is API-key only: Google ended personal sign-in for it in June 2026.

Based on each company's published terms and guidance as of November 2026. Terminus isn't affiliated with or endorsed by Anthropic, OpenAI or Google.
