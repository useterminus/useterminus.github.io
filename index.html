01 / Context

Nothing gets lost. Not between agents, people, or months.

Teams pass context around in notes and .md files, and most of it still goes missing: why something was done, what was tried and dropped. Terminus keeps the conversation itself, and gives every agent the part it needs.

Why is this line like this?

Point at any line and open the conversation that wrote it. Terminus follows git blame to the turn that made the commit, or matches the line against what each turn added.

src/charge.ts⌥⌘Y

14 return retry(() => processor.charge({ amount }), { attempts: 5 });

Why is this line like this?

Claude made the commit for this line · Nov 12 · "Billing webhook retries", turn 1

"Keep amounts in integer cents; the processor rejects floats."

Decided · Money stays in integer cents end to end. Floats were tried first and rejected by the processor.

Every agent catches up

An agent joining a thread is told what happened since it last spoke, whoever did it: another agent, or a teammate on another Mac.

After each turn, the lasting parts are saved as notes every agent reads, including approaches that failed, so nobody tries them again.

02 / Teams

One chat. Every teammate, on their own Mac and their own plan.

Share a thread and send the invite. Teammates join from anywhere and keep the subscriptions they already have: one on Claude Max, another on a ChatGPT plan, a third on local models. Your agent knows what theirs just did.

Work in the same thread, live

Everyone sees every turn as it happens. Teammates' turns carry their name, and nobody approves anyone else's permissions.

03 / Several agents

Put several agents on one job. Then have another check it.

Slash commands

Type / in the message box.

/swarm

Split the task, work at once, verify, fix.

/compare

Every agent answers, side by side.

/discuss

They take turns; the last sums up.

/review

A second agent checks the last change.

/recap

Where the thread stands, in a few lines.

/god

Work without asking, within limits.

/swarm, with a verifier

An agent that wrote none of the code reads every change and runs the tests. If it finds problems, the author fixes them.

Never stuck at a limit

When one agent hits its plan's limit, the best other agent continues in the same thread. You're warned before it happens.

Learns which agent is best

From your own history (changes kept or rewound, tests, what you said next) it scores agents by kind of task and suggests one as you type.

Companies check each other

A swarm can have Gemini check Claude's work, so a second model from another company reads every change before you do.

04 / Control

Decide how much it asks. Undo anything.

God mode, with limits

Agents edit, run and install without stopping to ask. Terminus still stops for anything that costs money, publishes, touches secrets or leaves the project.

Rewind and review every turn

Each turn is snapshotted before and after. Rewind puts files back exactly, without touching git. Review shows the diff file by file; revert any part or hand it to another agent.

05 / Your plans

Your subscriptions. Used the way each company allows.

Terminus never sees or stores your sign-in. Each agent signs in through its maker's own app on your computer. In a shared chat, each person's agents use that person's own plan.

Claude

Terminus runs the Claude Code you installed, unmodified, with Anthropic's own sign-in. Pro or Max works everywhere in Terminus, or use an API key.

Anthropic's terms let products run the unmodified Claude Code with each person's own subscription. Several Claude agents at once use your limits faster.

Codex

Sign in with your ChatGPT plan through Codex's own login. Usage counts against your plan's Codex allowance, or use an OpenAI API key.

OpenAI supports using ChatGPT plans in third-party tools.

Antigravity

On a personal Google sign-in, messages Terminus writes for it wait for you to read and send. With a Gemini API key it works everywhere; AI Pro and Ultra include monthly credits.

Gemini CLI is API-key only since June 2026.

Based on each company's published terms as of November 2026. Terminus isn't affiliated with or endorsed by Anthropic, OpenAI or Google. 19 agents are built in and 26 more come from the ACP registry; the project memory also works inside Claude Code, Codex, Cursor and VS Code.
