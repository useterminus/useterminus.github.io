Context

The reason behind the code doesn't get lost.

Teams pass context around in notes and .md files, and most of it still goes missing: why something was done, what was tried and dropped, what the customer actually said. Terminus keeps the conversation itself and gives each agent the part it needs.

Notes and .md filesTerminus
What's keptA summary someone remembered to writeThe whole conversation: every request, reply, command and file change
When it goes staleAs soon as the code moves onNever. It's the record of what happened, not a description of it
The whyUsually left outDecisions and abandoned approaches are saved as project notes every agent reads
Getting back to itSearch a folder and hopePoint at any line of code and open the conversation that wrote it
  • Every agent catches up on its ownWhen an agent joins or comes back to a thread, it's told what happened since it last spoke, whoever did it.
  • Why is this line like this?Put the cursor on a line and press Why. Terminus follows git blame to the turn that made the commit, or matches the line against what each turn added, and opens that conversation.
  • Decisions outlive the chatAfter each turn, a small model saves the durable parts: rules you set, commands that worked, decisions with their reason, and approaches that failed, so nobody tries them again.
  • Agents check before they change thingsMention a file and the agent gets its history. Agents can also ask about any line themselves, before undoing something that was done on purpose.

Teams

Work in the same chat as your teammates, each on your own computer and your own plan.

Share a thread and send the invite. Your teammates join from their Macs, wherever they are, and keep using the subscriptions they already have: one person on Claude Max, another on a ChatGPT plan, a third on local models. The conversation stays in sync, so your agent knows what your teammate's agent just did.

  1. SharePress Share next to the message box. Terminus makes a private invite for that chat.
  2. Send the invitePaste it to a teammate however you like: Slack, email, a message.
  3. They joinIn Terminus on their computer they choose Join, paste it, and pick their copy of the project. They see the whole chat and can send messages right away.

  • Each person's own subscriptionYour messages run on the agents signed in on your computer and count against your plan, never a teammate's. Nobody shares a login, an API key or a bill.
  • Any computers, anywhereChats go peer to peer between Macs, end-to-end encrypted, across offices and home networks. There's no Terminus server and no account to make.
  • Each person's own codeEveryone works on their own checkout; code moves through git as usual. Teammates' turns show their name, and nobody approves anyone else's permissions.

  • Catch up after being awayClose your laptop and open it later: Terminus reconnects and fills in what you missed, and a short "Since you left" card says what changed.

Several agents

Put several agents on one job, and have another check it.

Type a slash command, or pick how they should work from the agents menu.

/swarm

A quick plan splits the task. The agents work at once, then one that wrote none of it reads the changes and runs the tests. If it finds problems, the author fixes them.

/compare

Every agent answers the same message, side by side.

/discuss

They answer in turn, each responding to the others; the last one sums up.

/review

A different agent reviews the last change for bugs and missed requirements.

/recap

A few sentences on where the thread stands.

/god

Let agents work without asking, within the limits below.

Control

Decide how much it asks, and undo anything.

God mode, with limits

Agents edit, run and install without stopping to ask. Terminus still asks before anything that costs money, publishes or sends data out, touches secrets, or reaches outside the project.

Rewind any turn

Every turn is snapshotted before and after. Rewind puts your files back exactly as they were, without touching your git history.

Review before you keep

See each turn's diff file by file, revert any part of it, or have another agent review it.

Your plans

Your subscriptions, used the way each company allows.

Terminus never sees or stores your sign-in. Each agent signs in through its maker's own app on your computer, and Terminus follows each company's rules for apps like it. In a shared chat, each person's agents use that person's own plan.

Claude

Terminus starts the Claude Code you installed, unmodified, and you sign in with Anthropic's own sign-in. Your Pro or Max plan works everywhere in Terminus. Or use an Anthropic API key.

Anthropic's terms let products run the unmodified Claude Code with each person's own subscription. Several Claude agents at once use your plan's limits faster.

Codex

You sign in with your ChatGPT plan through Codex's own login, and it works everywhere in Terminus. Usage counts against your plan's Codex allowance. Or use an OpenAI API key.

OpenAI supports using ChatGPT plans in third-party tools.

Antigravity

On a personal Google sign-in, Google allows Antigravity only while you drive it, so messages Terminus writes for it wait for you to read, edit and send. With a Gemini API key it works everywhere; Google AI Pro and Ultra include monthly API credits.

Gemini CLI is API-key only: Google ended personal sign-in for it in June 2026.

Based on each company's published terms and guidance as of November 2026. Terminus isn't affiliated with or endorsed by Anthropic, OpenAI or Google.
